# HOMEから移動した先の見づらさ：調査と改修

## 対象と判断

対象は特定の投稿機能ではなく、HOMEから各入口を押した後の体験。
既存の公開版（調査開始時の main: `6f38445`）とソースを確認した。
利用の前提は「新着を見る → 気になるものを選ぶ → 詳細・原稿を使う」。

原因は次の3点に分けた。

1. 移動先の現在地が不明瞭。HOMEの「AI」を押しても見出しは「未確認」。
   共通ナビゲーションが消え、自動スクロールで旧ナビも画面外へ移る。
2. 画面への移動、状態、分野、個別の制作工程が似たボタンで並ぶ。
   前の画面の集計が読み込み中に残り、専用画面の集計とも重複する。
3. 一覧の各項目に、根拠・制作工程・全文・操作を展開している。
   候補を選ぶ前に詳細を読む量が多い。

ページ長・ボタン数は負担の場所を示す観察値であり、使いやすさを単独で証明する指標にはしない。
改修後の利用者による読みやすさ・選びやすさの評価は未実施。

## 入口ごとの整理

| 入口 | 観察した構造 | 今回の対応 |
|---|---|---|
| カード投稿 | 全文と工程を一覧内で展開。HOMEの候補と初期状態が一致しない場合がある | 新着一覧を入口にし、詳細を1件ずつ開く |
| お金投稿・家投稿 | HOME名と移動先名が不一致。共通カードに投稿制作パネルを追加 | HOMEと同じ見出し、短い一覧、既存原稿画面への直接ボタン |
| 仕入れ | 全体ナビに加え9区分、説明文、商品詳細が重なる | 共通ナビと仕入れ内の区分を分離。説明を折り畳み、商品を概要表示 |
| 海外差 | 旧共通ナビと専用ナビ・集計が重なる。長い価格比較の一覧 | 見出し・移動を共通化、説明・集計を折り畳み、詳細を個別展開 |
| AI・補助金・会社・お得・FP家計・SNS候補 | 見出しが状態名だけ。分野と状態が並列タブ | 分野を見出しにし、状態と分野を別々の選択欄にする |
| タスク結果 | 結果詳細はすでに折り畳み式 | 共通の見出しと分野選択、その他からの入口を用意 |
| 監視 | 別ダイアログ内の一覧と詳細 | 既存ダイアログへの入口を維持。表内のスケジュール原文は今回未変更 |
| 92・作業日報 | 別アプリを新しいタブで開く | 実際の入口を確認。「別タブで開く」と明示。別アプリ内部は今回の改修対象外 |

仕入れの台帳、追加調査、店の発見、監視の表を、投稿候補と同じ表示へ一律変更しない。
仕入れ・海外差の既存の並び替え条件も維持する。

## 実装上の約束

- HOMEと内部画面で同じ主要入口を使う。PCは上部、スマホは固定の下部ナビ。
- 内部画面にはHOMEへ戻るボタン、HOMEと同じ画面名、更新、その他の入口を置く。
- 一般情報は「状態」「分野」を選択欄に分離する。
- 項目の概要はタイトル、更新、状態、短い説明。商品では店舗・締切・想定利益も必要に応じて示す。
- 詳細は同じ一覧で1件ずつ開く。元のDOMを移すため、既存のボタン・編集・検証を保持する。
- HOMEで個別項目を押した場合は、移動先の該当項目を開く。
- 原稿・根拠・制作条件は既存画面を再利用する。記録や原稿の内容を変更しない。
- 空データと取得失敗を区別する。カード取得失敗を後続の工程描画で空表示に上書きしない。
- URLの履歴による画面復元は追加していない。画面移動はアプリ内ナビで行う。

## 確認方法と結果

本番の調査は閲覧とソース確認。改修版の操作確認は `scripts/ui-preview.mjs` のローカル環境で実施。
同環境はAPI通信を確認用データへ置き換え、本番へ記録を書き込まない。

起動: `node scripts/ui-preview.mjs`

- 通常: `http://127.0.0.1:8787/command-center-98/app-v130.html`
- 空データ: 同URLに `?empty=1`
- カード通信失敗: 同URLに `?fail=x-api`

確認済み:

- PC表示と390px幅で、主要画面への移動とHOME復帰。
- 一般情報の全7分野、未確認・確認済み・採用・却下・保存済みの切り替え。
- 仕入れの9区分を切り替え、選択状態と見出しを保持。
- スマホで主要画面、一般情報、仕入れ各区分のページ横はみ出しがない。
- 詳細を1件ずつ開き、別項目を開くと前の詳細を閉じる。
- カードの詳細・編集画面を開いて閉じ、一覧の開閉状態を保持。
- HOMEのカード・お金投稿の個別項目から該当詳細へ到達。
- お金投稿から既存の原稿・制作条件ダイアログへ到達。
- カードのXコピー後、成功通知とクリップボードの本文一致を確認。
- 海外差の詳細と編集入口、タスク結果の入口に到達。
- 新着0件の説明、通信エラーの説明・再試行・HOME復帰。
- 追加JavaScriptの構文チェック。

表示の高さは内容によって変わる。390px幅の確認用データでは、カード8件が約1360px、
お金原稿9件が約1888px。以前の本番実データとは内容が異なるため、削減率の比較には使わない。

本番APIへの保存・投稿・削除は検証していない。既存の保存処理はそのまま使用する。
公開後の実データによる最終確認と、利用者による読みやすさの評価は別途必要。

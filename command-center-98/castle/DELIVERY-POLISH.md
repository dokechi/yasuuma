# 小画面と初回配信の調整

- キャラ・原稿・4持ち場・検索・別案・読了・バックアップの機能を維持。短いスマホでは上段を圧縮し、状態ボタンは44px、注意表示は原稿や操作を覆わない通常の位置に展開する。
- `*-display.webp` は既存画像から同じピクセル寸法で作成した表示用派生画像（Sharp WebP quality 94 / alphaQuality 100 / smartSubsample）。原本は変更・削除していない。場面JPEG・音源も無変更。未使用の旧キャラ画像と書斎背景の先読みを抑える。
- DotGothic16は全8231文字マッピングを保ったWOFF2へ形式変換。元TTFと既存ライセンスを残し、未対応ブラウザのフォールバックに使用する。
- オフラインシェルは全モジュール、全場面JPEGと6つの表示用ポートレートを保持。BGMは再生時のみ取得し、シェル更新時にも既存の音源キャッシュを継承する。キャッシュ移行が容量不足になった場合は旧キャッシュから再生できる。
- 音設定を閉じてもBGMの再生中・待機・消音等を表示し、効果音を含む読み上げ名を更新する。保存済みONでも再読込後の明示操作は維持する。

## 計測条件

`CC_POLISH_BASELINE=1 NODE_PATH=... node scripts/castle-polish-browser.cjs`

同じPCのChrome、同じローカルサーバー・隔離データ・キャッシュなし・SW無効で、公開済み `e4fa514` と変更後を比較。場面を「お迎え」に固定し、自動切替の取得量を除いたホームから原稿表示までのResource Timingを合算し、注入したテスト用JS2本を除外する。実回線での体感速度や実機スマホの保証ではない。

初回セッション取得量: 12,898,925 → 5,121,299 bytes（約60.3%減）。390×667の本文領域: 46 → 192px。344幅の別案選択欄: 90 → 162px。390幅では90 → 208px。PCマップは4入口のラベルが1440×900内に入ることを検証する。

検証結果とスクリーンショットは `artifacts/castle-polish/` に出力する。通常のCIでは変更後の4画面寸法を検証し、比較用フラグは不要。

# 原稿操作とマップの確認

操作改善を先に実装・検証し、マップは次の段階で独立検証する。

| 操作 | 変更前 | 変更後 |
| --- | --- | --- |
| 持ち場を開く・選択原稿と位置を復帰 | 1タップ | 1タップ |
| 本文・リンクのコピー、原稿更新、音 | 各1タップ | 各1タップ |
| 検索に一致した別案を開く | 検索→グループ展開→案の3タップ | 検索→案の2タップ |
| 原稿から直前の検索結果へ | 検索を開き直し、再入力・再探索 | 1タップ、語・範囲・位置を保持 |
| 管理原稿の確認 | 一覧から対象を探す | 同じ元IDの対象へ直接移動。なければ一覧 |
| マップの建物から入る | 大きな長方形の入口を1タップ | 建物・小看板のどちらも1タップ |

同じ390×900pxの実Chrome比較で、本文領域は246pxから285pxへ、1440×900pxでは396pxから460pxへ拡大。通知が出る場合は通常フローで領域を確保し、本文・入口の上に重ねない。密集した操作ボタンは44px以上のタッチ領域を確保する。

検索は部屋ではその持ち場、ホームでは全持ち場を初期範囲とする。別案の一致は案名・本文・見出し・リンクから検索し、検索語がある場合のみ該当グループを開く。未検索の一覧は折り畳む。元IDが異なる原稿を見出しから推測して統合しない。

端末内の非表示は原稿本体を消さず、`hidden:`名前空間に復元用のスナップショットと表示状態を保存する。再読み込み後も復元でき、非表示原稿は原稿書き出しにも含む。書き出しに読了・コピー履歴や設定は含めない。旧形式のマーカーは元原稿が残っている場合に復元する。過去の形式で本文が既に失われている場合に推測で再生成はしない。

マップは既存の1枚の絵を利用する。建物の大きな透明タップ領域と44px以上の小さい入口看板を重ね、常時動かすのは窓灯り3要素・煙2要素のみ（面積合計はマップの約3%）。奥行きは静的な光・前景で示し、タップ時の短い寄りは操作を待たせない。新しい描画ループや画像を追加せず、動きをひかえめにする設定・reduced motion・非表示時には装飾を停止する。

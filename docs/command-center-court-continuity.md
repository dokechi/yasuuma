# Courtyard continuity — staged finish pass

Baseline: PR95, main `53b5de383e14a2c9d3971853d117987bc80115d4`.
The illustrated castle stays the default and all existing account/reader/data
owners remain authoritative. The optional 3D courtyard is not a complete 3D
interior system or a claim of parity with the user's visual references.

## Acceptance order

1. **One-context feasibility.** Prove in owned software-WebGL CI that the exact
   existing canvas/context can be leased into a same-origin parent presentation
   surface, receive parent-driven real frames while its child iframe is hidden,
   and return to the exact original DOM position without context loss or orphan
   rendering. No model changes are needed for this diagnostic.
2. **Insurance vertical slice.** Separate the existing native door into a static
   frame and two capped, hinged leaves. Preserve the closed appearance and
   authored room identity. From the actual painted camera, approach the same
   physical doorway; only full opaque wood coverage permits switching the world
   to a transparent portal-only layer. Opening the real leaves reveals the
   already-committed original reader. Back reverses the same passage.
3. **Actual visual gate.** Inspect deterministic contact/approach/occlusion/reveal/
   landed and reverse frames on phone, Fold and desktop. No ghost actor/paper,
   incorrect-room jump or transparent-door shortcut is acceptable.
4. **Full supported route integration.** Extend only after the slice is accepted.
   Native sourcing needs an explicit host lifecycle contract; until proven it
   remains immediate rather than pretending an unsupported journey succeeded.
   Apply one coherent, bounded material/light finish after functional continuity.
5. **Release gate.** All related and aggregate checks at the exact head,
   independent UX/art review, parent visual acceptance, then authorized merge,
   Pages and public runtime bytes/cache verification. Synthetic fixtures do not
   establish authenticated production-data or physical Fold GPU performance.

## Ownership contracts

- Router: existing board, application and native host. Commit immediately; never
  await animation, image decode or a camera promise.
- Renderer: one canvas/context, original GPU resources, authored camera/door
  transforms and a single bounded presentation lease. Normal demand rendering
  pauses during a lease; the compositor drives its short-lived manual frames.
  New route/selection state must survive a stale lease's finish/cancellation.
- Compositor: parent-document inert/aria-hidden/pointer-none surface, normalized
  clock, exclusive canvas lease and exact restoration. It never owns records,
  routes, focus or source mutations. It may use a detached, sanitized copy of an
  already-rendered departure foreground; it must never steal live reader DOM.
- Controller: chooses optional presentation versus true instant route, preserves
  latest intent, and supplies current geometry/foreground. Direct work routes,
  reduced motion and unavailable optional modules always remain immediate.

Alpha-capable context initialization does not make the ordinary courtyard
transparent: its sky remains opaque. World-to-portal visibility changes are
allowed only behind fully opaque closed leaves. Parent-driven rendering is an
exception bounded to the lease lifetime, not an always-on background loop.

## Cleanup and interruption

Newer intent, copy/tap/Tab, Escape, Back, hidden document, resize/Fold change,
context loss, failed adoption, pagehide and destruction must terminate the visual
surface without stranding focus, blocking the committed task or leaking a second
context. Canvas identity, original parent/next sibling, inline style, dimensions
and desired normal rendering state are restored exactly once. A detached or
unavailable same-origin host fails open to the normal route.

## Budget and art

The accepted insurance prototype used **52 primitive groups**, versus PR95's48.
The full-five authoring target is at most64 (actual exported and shadow-inclusive
render counts must be measured, not inferred from the forecast). Hard validation
remains **2,000,000 GLB bytes / 60,000 triangles / 12 PBR materials / 64 groups**
plus **128 actual render calls**, including shadow/sky work. Existing
characters and high-resolution interiors remain unchanged. No new external
service, paid dependency, backend read/polling, authentication or security change.

## Full-five finish contract

The accepted insurance slice establishes the single-context visual approach, not
that every future mechanism is physically valid. Subsequent swept-volume checks
found that swinging the whole lower arched fanlight could meet the balcony above.
The final lower three portals therefore keep their existing upper arch/fanlight
fixed and hinge only the wooden door leaves and original knobs. The archive uses
paired leaves and the observatory one native casement. Closed fronts, room colors
and building envelopes remain. Local rear pockets must accommodate the actual
swept solids; metadata alone cannot claim clearance. Revised mechanisms, including
insurance, require new all-width seal/crossing/return evidence.

Material work is deliberately bounded: fewer varied paving courses, quieter
stone color variation and one small original shared oak map if the final byte
budget permits. No extra props, borrowed art, bloom, new room meshes or synthetic
activity lights are needed. The existing warm study light is atmosphere only.

Native sourcing keeps its existing host route. The matching same-origin document
`cc:castle-native` event acknowledges the expected iframe hide; the compositor
still requires the actual visible sourcing workspace before revealing it. An
expected child-only resize is tolerated only while that native hide is valid or
when the restored frame and parent dimensions exactly match. Real parent resize,
orientation, hidden document or context loss always cancels presentation.

On native Back, `cc:castle-home` captures the already-rendered workspace before
the owner resets its view. The optional bounded snapshot preserves current text,
static filters and scrolling without fetching data, moving live DOM or keeping
handlers/IDs. Editors, unsupported content, unavailable artwork or exceeded
budgets give immediate normal Back. A slow optional snapshot module cannot block
publishing-room passages. Detached departure copies expire if the canonical
return never resumes. Nothing in this layer posts, saves or edits source records.

Final browser coverage includes every ordinary room entry/return, native sourcing
hide/restore, actual nonzero reader scroll and tools foreground, direct zero-clock
routes, interrupted/newer intent, missing enhancement and reduced-motion fallback.

# 仕入れ候補のスマホ比較

公開main cf17fd9を起点に、表示だけを変更。Supabase・認証・権限・RPC・データ保存経路は変更しない。

- 700px以下で商品名の下に総合S/A/B/C、一言根拠、発見月日、仕入価格、推奨数量を表示。
- 総合は保存済みoverall_grade/overall_rating/総合、または既存priorityを使用。スコアから新しい段階を推定せず、未対応値・欠損は未確認。
- 発見はfirstSeen/detectedAt/createdAt等の発見情報をJSTで表示。lastSeenを発見日時へ転用しない。
- 商品・メルカリ・ヤフーフリマの保存済みhttp(s)根拠リンクと、既存詳細を開くボタンを追加。
- 保留・価格待ちの入力値、既存のイベントと保存処理、相場履歴・注記は詳細に保持。詳細ボタンは既存summaryクリック経路のみを使用し、再描画・通信・保存をしない。
- PCでは追加表示を非表示にし、従来の概要と詳細テーブルを維持。相場の横長表は既存の局所スクロールを維持。
- 既存CCNavigation.decorate内から表示装飾を呼ぶ。renderSourcingラッパーやMutationObserverは追加しない。順序・件数には既存表示モデルを使用。

## 検証と限界

実際のheadless Chromeで合成データを使い320/375/390/700/1024pxを検証。各幅29確認：横はみ出し、4段階、発見と更新の区別、0と欠損、根拠リンク、詳細ボタン・キーボード開閉、入力ノード/値と既存保存bindingの保持、表示操作による保存なし、元レコード不変、PCテーブル保持。

これはブラウザーの幅検証であり、実スマホの速度・タッチ操作・本番データ全件・本番の全ラッパー連鎖を検証した意味ではない。親の認証済み現行画面確認とレビュー後に本番反映を判断する。
